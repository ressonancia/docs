# Frequently Asked Questions

This list is a compilation of questions that we have received from all channels including email.

If you dont find what you are looking for inside this list send an email to support@ressonance.com. Whe will be very happy to assist you.


## Is this Laravel Reverb?

It is a cloud implementation of Reverb using the WebSocket protocol. Stop restarting your server after every deployment and focus on building your application without worrying about the underlying infrastructure.

## What is the advantage compared with self-hosted Reverb?

Running a self-hosted Reverb instance comes with engineering and infrastructure costs, and it does not work well on shared hosts. Ressonance removes those headaches.

## Then to use Ressonance i just need the Laravel Reverb Broadcast Driver?

Yes. Just follow the Laravel documentation and you are good to go.

## How does it compare with Pusher?

Pusher has a wide feature set but can be expensive. Most applications just need channels and push notifications, and Ressonance can deliver those at a lower cost.

## Is Ressonance only for Laravel applications?

Ressonance is built for Laravel applications, but Reverb is compatible with the Pusher API. That means you can use Ressonance with other stacks as well.

## Can I use Pusher libraries to integrate with Ressonance?

Yes, but Pusher has more features than Ressonance provides. Only channels are supported.

## Is there a contract commitment?

No. You can leave whenever you want.

## What about security?

Ressonance does not store your messages for compliance purposes. All communication is encrypted.

## Can Ressonance help with the first steps?

Absolutely. On paid plans we are happy to help your team with the first steps, including hands-on support.
