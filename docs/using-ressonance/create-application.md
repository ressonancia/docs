# Create Ressonance Application

After creating an account you should create an application key inside Ressonance. Then you can use the keys inside your application.

![Create Ressonance App Form](../assets/create-app.png)

Proceed with "Create Project" button your application key will be generated.


![Create App Key Form](../assets/create-app-key.png)


Just use the app key with a pusher compatible API. For Laravel applications you can use Reverb like the [following link](https://laravel.com/docs/11.x/broadcasting#client-reverb)
